# Matchly 🚀

> Match smarter. Apply better.

Matchly is an AI-powered ATS Resume Analyzer that helps job seekers compare their resume against a job description.

## ✨ Features

- Upload Resume (PDF)
- Paste Job Description
- AI-powered Resume Analysis
- ATS Compatibility Score
- Missing Skills Detection
- Resume Improvement Suggestions

## 🛠️ Tech Stack

## Frontend
- React
- Vite
- Tailwind CSS

## Backend
- Flask
- Python

### AI
- Google Gemini API
